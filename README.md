# manaba課題(未提出課題管理PWA)

文教大学 manaba の未提出課題を、iPhone で締切順に管理するアプリです。
サーバーは使わず、データはすべて iPhone の中に保存されます。ID・パスワードは扱いません。

## できること(v1)
- 課題を締切順に表示(24時間以内=赤、3日以内=黄、期限切れ=グレー)
- 完了チェック(完了した課題は「完了済み」にまとまる)
- 課題名をタップすると manaba の課題ページを開く
- 手動で課題を追加
- manaba の一覧から消えた課題には「manabaの一覧にありません(提出済み?)」と表示(自動では完了にしない)

## 時間割
- 学期ごと(例: 2026年度 秋学期)に別々に保存。画面上のメニューで学期を切り替え(前後の学期は空でも選べる)
- 4〜8月=春学期、9〜翌3月=秋学期。新しい学期になると、開いたときに自動でその学期に切り替わる(前の学期は残る)
- manaba からの取り込みは、表示中の学期に入る。単位は「この学期」と「全学期の合計」を表示
- 下のタブで「課題」「時間割」を切り替え
- 月〜土 × 1〜5限(1限 9:10〜10:40 / 2限 10:50〜12:20 / 3限 13:10〜14:40 / 4限 14:50〜16:20 / 5限 16:30〜18:00)
- manaba の「コース」→「曜日」表示のページで「manaba取込」を実行すると、時間割をまとめて取り込める
  (同じコマに複数の授業があっても両方入る。再取り込みしても、同じ授業の教室・単位数などは残る)
- コマを押して授業名・教室・先生・単位数・manabaのコース名を登録(手入力も可)
- 今日の列・今の時限を強調表示。上に「今の授業」「次の授業」を表示
- manabaのコース名が一致する未完了課題の数をコマに表示し、押すと一覧が見られる
- 登録した授業の単位数の合計を表示(同じ授業名は1回だけ数える)

## 出席管理
- 時間割のコマを押すと「出席/遅刻/欠席」を日付ごとに記録(同じボタンをもう一度押すと取り消し)
- 授業中(または今日さっき終わった授業)は、時間割画面の上から1タップで記録
- ルール: 全15回、欠席が3分の1以上(5回)で単位NG → 4回まで休める、遅刻1回=欠席1回
  (授業ごとに回数・遅刻の数え方を変更可)
- 残りが2回以下で黄、1回以下で赤。コマに「欠2/4」のように表示
- 時間割画面の下「出席のまとめ」から授業ごとの記録一覧を開ける(すべて/欠席/遅刻/出席で絞り込み、その場で変更・削除・追加)

## バックアップ
- 課題タブの「データのバックアップ」から、全データをJSONファイルに書き出し/読み込み

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `bookmarklet.js` | manaba の表を読み取るブックマークレットの中身 |
| `bookmarklet.html` | ブックマークレットの設定ページ |
| `manifest.webmanifest` / `sw.js` / `icons/` | ホーム画面追加・オフライン用 |

ビルド作業は不要です。ファイルを編集して GitHub に push すれば反映されます。
`app.js` などを変えたときは、`sw.js` の `CACHE` の番号(`v1` → `v2`)も上げてください。

## GitHub Pages で公開する
1. GitHub でこのリポジトリを開き、**Settings** → 左メニューの **Pages** を開く
2. 「Build and deployment」の **Source** を「Deploy from a branch」にする
3. **Branch** で公開するブランチ(例: `main`)と `/ (root)` を選んで **Save**
4. 1〜2分待つと、ページ上部に `https://ユーザー名.github.io/my-app/` のようなURLが表示される

※ 無料プランでは、リポジトリが **Public(公開)** でないと GitHub Pages を使えません。

## iPhone に入れる
1. iPhone の **Safari** で公開URLを開く
2. 共有ボタン(□に↑)→「**ホーム画面に追加**」
3. アプリの「ブックマークレットの設定」を Safari で開き、手順どおりにブックマークを登録する

## manaba から取り込む
1. アプリの「① manabaを開く」で、Safari に未提出課題一覧を開く(x-safari-https で標準ブラウザに関係なく Safari を開く)
2. アドレスバーに「manaba取込」と入力して、ブックマークをタップ
3. 「コピー」を押す
4. ホーム画面のアプリで「manabaから取り込む」を押す(1タップで取り込み。最後の取り込みから1日たつとお知らせを表示)

iPhone では、ホーム画面のアプリと Safari のタブで保存場所が別々なので、クリップボード経由で渡しています。
