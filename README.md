# manaba課題(未提出課題管理PWA)

文教大学 manaba の未提出課題を、iPhone で締切順に管理するアプリです。
サーバーは使わず、データはすべて iPhone の中に保存されます。ID・パスワードは扱いません。

## できること(v1)
- 課題を締切順に表示(24時間以内=赤、3日以内=黄、期限切れ=グレー)
- 完了チェック(完了した課題は「完了済み」にまとまる)
- 課題名をタップすると manaba の課題ページを開く
- 手動で課題を追加
- manaba の一覧から消えた課題には「manabaの一覧にありません(提出済み?)」と表示(自動では完了にしない)

## 画面の構成(下のタブ)
- **今日**: 大学への行き方 / 試験 / 今日の授業と出席 / 締切が近い課題 / 記録し忘れ
- **やること**: すぐ追加・詳しく追加 / リスト・カレンダー / 完了済み
- **時間割**: 学期の切り替え / 今の授業 / 表 / 出席のまとめ・試験の予定(折りたたみ)
- **その他**: manaba・Bナビからの取り込み(課題・時間割・教室) / ブックマークや出発地などの設定 / バックアップ
- 上の「① manabaを開く ② 取り込む」は「今日」「やること」だけに表示

## 今日
- アプリを開くと最初に表示。今日の日付・学期・休講日などのお知らせ
- 今日の授業(時限・教室・第何回・授業中/終了)と、出席の記録ボタン・欠席の残り回数・課題数
- 前の日までの記録し忘れ、48時間以内に締切の課題、取り込み忘れのお知らせ
- 授業がない日は「次の授業」を表示
- 一番上に「大学への行き方」: 着きたい時刻(初期値は次の授業の10分前)で、Googleマップ(経路URLの data パラメータで「到着」と時刻を指定)を開く。今すぐ出る/自転車/車/徒歩も。出発地(家の住所など)は任意で、この端末の中だけに保存
- Bナビ(教室の確認用)へのリンクを、今日画面・時間割画面・コマの画面に配置(Safariで開く)

## やることリスト(「やること」タブ)
- manabaの課題と自分のやることを1つのリストで管理。「期限切れ/今日/明日/1週間以内/それより先」に分けて表示
- 上の入力欄に書いて「今日/明日/今週末」か「📅 日付を選ぶ」(カレンダーが開く)で日付を決めて追加(Enterでも追加)
- 「すべて/manabaの課題/自分のやること」で絞り込み
- 「リスト/カレンダー」切り替え: 月のカレンダーに締切の件数(赤=24時間以内・期限切れ、黄=3日以内)、試験の日に「試」、定期試験期間は紫、休講日は灰色(下に色の説明)。日付を押すとその日の一覧と「＋ この日にやること」
- 「✎」で編集: 自分のやること・手動の課題は内容・授業・日付・時刻・リンク・メモを変更/削除。manabaの課題はメモだけ(取り込み直しても残る)

## AIに相談(💡)
- 課題・やることの💡から、課題の内容(manabaの説明を貼る)と自分のメモを入れて、相談の種類を選ぶ
  (回答の方向性を提案 / 構成案 / 下書きへのアドバイス / 進め方の計画 / そのままClaudeに聞く=自分の質問と課題の情報だけを送る)
- 未提出課題一覧で「manaba取込」を押すと、各課題のページを裏で1件ずつ(0.3秒おき)読んで「問題」の説明もまとめて取り込む
  (「説明は読まずにコピー」で途中でやめられる。自分で書き直した説明は上書きしない)
- manabaの課題ページで「manaba取込」→「コピー」→アプリで「取り込む」で、課題の説明文をその課題に保存して「AIに相談」を開く
  (「課題内容」などの見出しがなければ、メニューや日時を除いた一番長い文章を使う。それでも違うときは説明文を長押しで選んでから実行。相談画面の「コピーした内容を入れる」「manabaで課題を開く」も使える)
- 「Claudeで相談する」で頼み方の文章を作って claude.ai の新しい会話を開く(同じ文章をコピーもする)
- 完成した文章ではなく、論点の案・根拠の例・構成・キーワードを提案してもらう頼み方にしている。サーバー・APIキーは使わない

## やること・試験の予定
- 「やること」(例: 小テストの勉強)を授業にひも付けて登録。日付だけでも時刻付きでもOK。課題と一緒に締切順に並ぶ
- 試験の予定(授業・種類・日付・時限・メモ)を登録。定期試験は試験期間の初日が初期値
- 今日画面に「今日の試験」と30日以内の「もうすぐ試験」(あと◯日、前日・当日は赤)を表示
- 時間割画面の下に試験の一覧、コマの画面からも「＋ やること」「＋ 試験の予定」で追加

## 時間割
- 学期ごと(例: 2026年度 秋学期)に別々に保存。画面上のメニューで学期を切り替え(前後の学期は空でも選べる)
- 4〜8月=春学期、9〜翌3月=秋学期。新しい学期になると、開いたときに自動でその学期に切り替わる(前の学期は残る)
- manaba からの取り込みは、表示中の学期に入る。単位は「この学期」と「全学期の合計」を表示
- 下のタブで「課題」「時間割」を切り替え
- 月〜土 × 1〜5限(1限 9:10〜10:40 / 2限 10:50〜12:20 / 3限 13:10〜14:40 / 4限 14:50〜16:20 / 5限 16:30〜18:00)
- manaba の「コース」→「曜日」表示のページで「manaba取込」を実行すると、時間割をまとめて取り込める
  (同じコマに複数の授業があっても両方入る。再取り込みしても、同じ授業の教室・単位数などは残る)
- Bナビの「MYスケジュール」で日付を選んで「manaba取込」→ 曜日ごとにたまり、まとめてコピーして教室を取り込める
  (曜日+時限で授業を探し、Ⅱ/２/II などの書き方の違いはそろえて比べる。前半・後半のコマは授業ごとに教室を保存)
- コマを押して授業名・教室・先生・単位数・manabaのコース名を登録(手入力も可)
- 今日の列・今の時限を強調表示。上に「今の授業」「次の授業」を表示
- manabaのコース名が一致する未完了課題の数をコマに表示し、押すと一覧が見られる
- 登録した授業の単位数の合計を表示(同じ授業名は1回だけ数える)

## 出席管理
- 時間割のコマを押すと「出席/遅刻/欠席」を日付ごとに記録(同じボタンをもう一度押すと取り消し)
- 授業中(または今日さっき終わった授業)は、時間割画面の上から1タップで記録
- ルール: 全15回、欠席が3分の1以上(5回)で単位NG → 4回まで休める、遅刻1回=欠席1回
  (授業ごとに回数・遅刻の数え方を変更可)
- 残りが2回以下で黄、1回以下で赤。コマに「欠2/4」のように表示
- 時間割画面の下「出席のまとめ」から授業ごとの記録一覧を開ける(すべて/欠席/遅刻/出席で絞り込み、その場で変更・削除・追加)

## 記録し忘れのお知らせ
- 授業が終わったのに出席を記録していない授業を、時間割画面の上に一覧表示(その場で記録できる)
- 「時間割」タブとアプリのアイコン(対応している場合)に件数を表示
- 数えるのは、この機能を使い始めた日以降の授業日(年間予定がある学期のみ)
- 決まった時刻の通知はサーバーなしではできないため、iPhoneのリマインダー(例: 平日18:10)の併用をおすすめ

## 前半・後半で分かれる授業
- 1つのコマに授業が2つある場合は、授業ごとに出席を記録(各8回・休めるのは2回まで)
- 前半 = そのコマの第1〜8回の授業日、後半 = 第9回以降(足りない回は日付を選んで追加)
- どちらが前半かは、コマの画面の「前半と後半を入れ替える」で変更(初期値はmanabaの表で上の授業が前半)
- 授業中の1タップ記録は、その日が前半か後半かで自動で振り分け

## 年間予定(授業日カレンダー)
- `calendar.js` に越谷キャンパスの2026年度行事予定(春: 4/9〜7/27、秋: 9/5〜1/19)を入力
  (休講日・休業期間・祝日授業日。各曜日15回の授業日がPDFの①〜⑮と一致することを確認済み)
- 今の授業に「第10回」と表示、休講日・休業期間・試験期間・祝日授業日を時間割画面の上に表示
- 出席の記録画面に、今日までの授業日を全部並べる(記録していない日は「未記録」で、その場で記録できる)
- 新しい年度の行事予定が出たら `calendar.js` に追加する

## バックアップ
- 課題タブの「データのバックアップ」から、全データをJSONファイルに書き出し/読み込み

## 自動テスト
- `tests/` に、ブラウザでアプリを実際に動かして確かめるテスト(Playwright)が入っている
  - 年間予定の授業日がPDFと一致するか / ブックマークレットの読み取り / 取り込み・データ変換・学期の切り替え
  - 出席(1タップ記録・記録画面の編集・前半/後半・記録し忘れ) / 今日画面 / やること・試験 / バックアップ
- GitHub に push すると、GitHub Actions が自動でテストを実行する(結果はリポジトリの「Actions」タブ)
- 自分のパソコンで動かす場合: Node.js を入れて `npm install` → `npx playwright install chromium` → `npm test`

# 空き時間アプリ(`aki/`)

TimeTree の予定を取り込んで、自分の空き時間を表示する別アプリです(manaba課題アプリとは別にホーム画面に追加します)。
公開URLは manaba課題アプリのURLの後ろに `aki/` を付けたもの(例: `https://ユーザー名.github.io/my-app/aki/`)。

## できること
- **週**: 7日分のタイムライン。予定=グレー、空き=緑(開始時刻と長さ)、今の時刻=赤線、時間外=薄いグレー
- **月**: 日ごとの空き時間(◯h)を緑の濃さで表示。押すとその日の予定と空き
- **リスト**: 2週間分の空き時間を「30分/1時間/2時間/3時間/4時間以上」で絞り込み。「この空き時間をコピー」で LINE などに貼れる文章を作る
- 上のカードに「今日のこれからの空き」と「次の空き」
- 設定: 空き時間を数える時間帯(平日/土日)、短いすき間を除く、予定の前後に空ける時間(移動など)、終日の予定を空きなしにするか、カレンダーごとに計算に入れるか(家族の予定を外すなど)
- 予定を押して「この予定があっても空きとして数える」(リマインダー的な予定など)
- 繰り返し予定(毎週・毎月第◯曜日など)・除外日に対応
- Googleカレンダーなどの `.ics` ファイルも読み込める

## TimeTree から取り込む
TimeTree の公式APIは2023年12月に終了したため、manaba と同じくブックマークレットを使います。
ログイン中の TimeTree Web版(timetreeapp.com)が使っている読み取り用のURLを同じページから呼び、予定をコピーします。
パスワードは扱わず、予定は読み取るだけです。TimeTree 側の変更で動かなくなる可能性があります。

1. 最初に1回だけ: `aki/bookmarklet.html` を Safari で開き、ブックマーク「TimeTree取込」を登録
2. アプリの「取り込む」→「① TimeTreeを開く」→ ログイン
3. ブックマーク「TimeTree取込」→「コピー」
4. アプリに戻り「取り込む」→「② 貼り付けて取り込む」

取り込むたびに TimeTree の予定はまるごと入れ替わります(.ics で読み込んだカレンダーはそのまま)。

## ファイル
| ファイル | 内容 |
|---|---|
| `aki/index.html` / `aki/style.css` / `aki/app.js` | 画面 |
| `aki/core.js` | 計算(タイムゾーン・繰り返し予定の展開・.ics の読み込み・空き時間) |
| `aki/timetree.js` / `aki/bookmarklet.html` | TimeTree取込ブックマークレットとその設定ページ |
| `aki/manifest.webmanifest` / `aki/sw.js` / `aki/icons/` | ホーム画面追加・オフライン用(変更したら `aki/sw.js` の `CACHE` を上げる) |

保存場所は `localStorage` の `akiJikan`(この端末の中だけ)。テストは `tests/aki.spec.js`。

## manaba課題アプリの授業を入れる
- manaba課題アプリの「時間割」タブの下にある「授業の時間を『空き時間』アプリに送る」を押す(授業と、時限の入った試験の予定がコピーされる)
- 空き時間アプリの「取り込む」→「貼り付けて取り込む」。カレンダー「授業(manaba)」として入り、設定で外すこともできる
- 授業日は `calendar.js` の年間予定(休講日・冬季休業などを除く)から作る。時間割を変えたら送り直す
- Safari やパソコンなど、2つのアプリの保存場所が同じときは、空き時間アプリを開くだけで自動で読み込む

## 空き時間アプリから TimeTree に予定を入れる
1. 空き時間アプリで、空き時間(リストの時間、日付の詳細の「＋ 予定」)を押す
2. 予定の名前・時間を決めて「TimeTreeに入れる」(入れる先は「自分用カレンダー」だけ)(コピーされ、アプリでは「追加待ち」として表示)
3. 「TimeTreeを開く」→ ブックマーク「TimeTree取込」→「コピーした予定をTimeTreeに追加」→ 出てきた入力ダイアログに貼り付けて「OK」→ 内容を確かめて「追加する」(TimeTreeのページではクリップボードの読み取りもページ内の入力欄も使えないことがあるため、iPhone標準の入力ダイアログを使う)
4. 続けて出る「コピー」→ アプリで「貼り付けて取り込む」(TimeTreeに入った予定は「追加待ち」から外れる)

書き込みは Web版と同じ `POST /api/v1/calendar/{id}/event`(ページの CSRF トークン付き)。同じ名前・同じ開始時刻の予定がすでにあれば追加しない。
ブックマークレットの中身を変えたので、`aki/bookmarklet.html` から登録し直す必要がある。

## 自動テストと公開
`claude/...` ブランチから公開ブランチ(`claude/manaba-task-pwa-728utb`)へのプルリクエストは、GitHub Actions がテスト → 合格ならマージ → 公開ページに反映されたかの確認まで自動で行う(`.github/workflows/test.yml` の `automerge`)。

## シフト希望の文章(「シフト」タブ)
- 水曜日に、次の週(月〜日)のシフト希望を LINE で出す用の文章を作る。水曜日は上に「今日はシフトの提出日です」と出る
- 営業時間 11:00〜14:00・16:00〜22:30(土日は23:30まで)のうち、3時間以上空いている時間(授業・予定・空きコマを除く)。開始は30分単位で切り上げ、終わりは切り捨て。閉店までなら「ラスト」
- 文章は手で直せる(描き直しで消えない)。「コピーする」→「LINEを開く」で貼り付けて送る
- 営業時間などは `aki/core.js` の `SHIFT_DEFAULT`
